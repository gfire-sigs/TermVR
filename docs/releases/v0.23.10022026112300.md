# TermVR v0.23.10022026112300

`TermVR` `v0.23.10022026112300` (`versionCode` `302300020`) bundles `gvx` `v0.23.10022026112300` (`52e94052d139`). It updates the embedded sandbox kernel to `gVisor` `release-20261123.0` and migrates native packaging and execution from `librungv.so` to `librungvx.so`.

## What changed

This release updates the embedded runtime to upstream `gvx` `v0.23.10022026112300` and completes the `rungvx` binary migration. All existing container profiles, workspaces, and persistent `ext4lite` volumes stay compatible.

### Runtime upgrade to `gvx` `v0.23.10022026112300`

Upstream `gvx` `v0.23.10022026112300` syncs `gVisor` to `release-20261123.0` (`83df8eae069e`) and hardens filesystem capability handling and netstack state isolation.

- Upgraded pinned `gvx` runtime to `v0.23.10022026112300` (`52e94052d139`), bringing EROFS tail-packed inline data, TCP Delayed ACKs, `seccomp` filter cache reuse, overlay stacking depth limits, and `epoll_ctl` `EPOLLEXCLUSIVE` validation.
- Included raw v3 file capability `xattr` read fixes in `hostfs`, `ext4lite`, and `erofs`, plus per-stack netstack isolation cleanups across `tcp`, `ipv4`, and `netfilter`.
- Updated `CheckpointController.DEFAULT_GVX_VERSION`, `scripts/source-lock.json`, `gradle/libs.versions.toml`, `fdroid/dev.gfire.termvr.yml`, and bundled license notices.

### Migration from `librungv.so` to `librungvx.so`

Upstream `gvx` `v0.23` renamed the CLI package and Android library from `rungv` (`librungv.so`) to `rungvx` (`librungvx.so`) (`gvx#250`).

- Updated `scripts/build-native-deps.sh` and `scripts/source-lock.json` to compile `./cmd/rungvx` into `jniLibs/<abi>/librungvx.so` and remove stale `librungv.so` artifacts.
- Updated `SandboxForegroundService`, `SandboxRuntimeGateway`, and `SandboxSupervisor` to execute `librungvx.so` from `applicationInfo.nativeLibraryDir`.
- Updated `GvxCommandBuilder.parsePublishingLine` to parse `rungvx: publishing` stderr lines while retaining compatibility with legacy `rungv: publishing` lines.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.23.10022026112300-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.23.10022026112300`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.23.10022026112300-arm64-v8a.apk --abi arm64-v8a
```
