# TermVR v0.29.10002026112300

`TermVR` `v0.29.10002026112300` (`versionCode` `302900000`) bundles `gvx` `v0.29.10002026112300` (`759be9bb3985`). It keeps all existing container profiles, workspaces, and persistent `ext4lite` volumes compatible.

## What changed

This release advances the embedded `librungvx.so` runtime from `gvx` `v0.27.10012026112300` to `v0.29.10002026112300`. It brings in upstream Android control-socket fallback fixes, cache hardening, and cross-platform runtime fixes.

### Runtime upgrade to `gvx` `v0.29.10002026112300`

Upstream `gvx` `v0.29.10002026112300` (`759be9bb3985`) keeps `gVisor` `release-20261123.0` (`83df8eae069e`) and incorporates both `v0.28` packaging updates and `v0.29` fixes. It hardens Android socket resolution, read-only cache access, and host-storage isolation.

- Upgraded pinned `gvx` runtime to `v0.29.10002026112300` (`759be9bb3985`), fixing named control sockets on Android to use `TMPDIR` or user cache directories instead of `/tmp` (`gvx#305`).
- Hardened unwritable-`HOME` cache fallback, ephemeral volume precedence, and read-only image CLI lookups (`gvx#297`, `gvx#302`).
- Included upstream allowlist sanitization for EL0 ID registers on ARM64 (`gvx#298`, `gvx#303`), separation of default Windows volume paths (`gvx#305`), and Linux AppArmor diagnostics (`gvx#299`, `gvx#304`).
- Updated `CheckpointController.DEFAULT_GVX_VERSION`, `scripts/source-lock.json`, `gradle/libs.versions.toml`, `fdroid/dev.gfire.termvr.yml`, and bundled license notices.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.29.10002026112300-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.29.10002026112300`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.29.10002026112300-arm64-v8a.apk --abi arm64-v8a
```
