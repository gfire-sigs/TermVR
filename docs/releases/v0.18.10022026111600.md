# TermVR v0.18.10022026111600

`TermVR` `v0.18.10022026111600` (`versionCode` `301800020`) upgrades the bundled `gvx` runtime to `v0.18.10022026111600` (`14ac125f1871`). It applies the `GHSA-424c-p5c6-jhhm` security fixes and `arm64`/`amd64` runtime hardening. It also defaults wake lock to indefinite until containers stop and packages a signed universal Android App Bundle (`.aab`).

## What changed

This release brings `gvx` `v0.18.10012026111600` and `v0.18.10022026111600` into `TermVR`, updates wake lock defaults, and adds universal AAB and F-Droid build fixes. Every section below summarizes the user-visible changes.

### Security hardening and gvx v0.18.10022026111600

The bundled `librungv.so` runtime closes 14 security findings reported in `GHSA-424c-p5c6-jhhm` and hardens 16 KB `arm64` and `amd64` instruction handling.

- Disabled guest-initiated `hostfs` and `erofs` `mount(2)` calls, blocked write opens on read-only `hostfs` workspaces after guest remount, and rejected `.gvx_meta` path traversal (`GHSA-424c-p5c6-jhhm`).
- Opened checkpoint bundle files through `os.Root` regular-file verification, bounded OCI tar path length and sparse hole budgets, and capped VXLAN transmit recursion (`GHSA-424c-p5c6-jhhm`).
- Rejected aliased extent, journal, and xattr blocks in `ext4lite` and updated `klauspost/compress` to `v1.20.5` to resolve `GO-2026-6865` (`GHSA-424c-p5c6-jhhm`).
- Hardened `arm64` 16 KB store emulation (`DC ZVA`, `CASP`, `STTR`) and `amd64` decoding and patching in `gvx` (`gvx#222`, `gvx#224`).

### Wake lock, F-Droid recipe, and AAB packaging

Background container wake locks now default to indefinite until all containers stop or freeze, and releases include a universal `.aab` package.

- Set default wake lock duration to indefinite (`0` minutes) when `POST_NOTIFICATIONS` is granted, falling back to 30 minutes when notification permission is revoked.
- Added an `Indefinite` quick action in `TerminalSessionDrawer` for active sessions.
- Updated `fdroid/dev.gfire.termvr.yml` to remove unregistered `srclibs` and stage build toolchains outside the source tree in `/tmp/termvr-toolchains`.
- Added `PRIVACY.md`, extended `verify-16kb-alignment.sh` to verify `.aab` archives, and shipped a signed universal `TermVR-v0.18.10022026111600.aab`.

Each release ships architecture-specific APKs and a universal AAB signed with Android APK Signature Scheme v2 and v3. One `arm64-v8a` binary supports both 4 KB and 16 KB page-size Android 12+ devices.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.18.10022026111600-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.18.10022026111600`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.18.10022026111600-arm64-v8a.apk --abi arm64-v8a
```
