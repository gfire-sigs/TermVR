# TermVR v0.22.10002026111600

`TermVR` `v0.22.10002026111600` (`versionCode` `302200000`) bundles `gvx` `v0.22.10002026111600` (`a90476e02630`). It updates the embedded sandbox runtime and hardens the automated upstream release tracking workflow.

## What changed

This release updates `librungv.so` to upstream `gvx` `v0.22.10002026111600` and improves automated release synchronization. All existing container profiles and persistent volumes stay compatible.

### Runtime upgrade to `gvx` `v0.22.10002026111600`

Upstream `gvx` `v0.22.10002026111600` extends `ext4lite` volume mount options and cleans up `systrap` startup unmap checks.

- Upgraded pinned `gvx` runtime to `v0.22.10002026111600` (`a90476e02630`), adding `size=SIZE` caps and bare `ephemeral` scratch mounts on `--mount type=volume` (`gvx#247`, `gvx#256`).
- Included checkpoint manifest version `3` support for capped persistent volumes and explicit `UNSUPPORTED` rejection when checkpointing ephemeral volumes.
- Updated `CheckpointController.DEFAULT_GVX_VERSION`, `scripts/source-lock.json`, `gradle/libs.versions.toml`, `fdroid/dev.gfire.termvr.yml`, and bundled license notices.

### Automated `gvx` release tracking workflow

`scripts/sync-gvx-version.sh` and `.github/workflows/sync-gvx.yml` now track published GitHub Releases and handle branch cleanup without churn.

- Updated `--fetch-latest` to resolve the latest published non-draft, non-prerelease GitHub Release, peel its commit SHA via `git ls-remote`, and block accidental `versionCode` downgrades.
- Updated `.github/workflows/sync-gvx.yml` to pass `SYNC_GH_PAT || GITHUB_TOKEN` to `actions/checkout`, skip redundant pushes, clean stale sync branches, and write `$GITHUB_STEP_SUMMARY` reports.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.22.10002026111600-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.22.10002026111600`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.22.10002026111600-arm64-v8a.apk --abi arm64-v8a
```
