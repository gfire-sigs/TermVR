# TermVR v0.27.10012026112300

`TermVR` `v0.27.10012026112300` (`versionCode` `302700010`) bundles `gvx` `v0.27.10012026112300` (`84ef48ab4b79`). It keeps all existing container profiles, workspaces, and persistent `ext4lite` volumes compatible.

## What changed

This release advances the embedded `librungvx.so` runtime to upstream `gvx` `v0.27.10012026112300` for checkpoint and control-plane stability fixes.

### Runtime upgrade to `gvx` `v0.27.10012026112300`

Upstream `gvx` `v0.27.10012026112300` (`84ef48ab4b79`) fixes stdio reader races during checkpoint serialization and stabilizes sandbox startup state reporting.

- Upgraded pinned `gvx` runtime to `v0.27.10012026112300` (`84ef48ab4b79`), quiescing host `stdin` and `TTY` readers across checkpoints and serializing kernel startup state (`gvx#283`).
- Included upstream `systrap` island-slot scrubbing (`gvx#284`) and test-suite synchronization fixes (`gvx#285`).
- Updated `CheckpointController.DEFAULT_GVX_VERSION`, `scripts/source-lock.json`, `gradle/libs.versions.toml`, `fdroid/dev.gfire.termvr.yml`, and bundled license notices.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.27.10012026112300-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.27.10012026112300`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.27.10012026112300-arm64-v8a.apk --abi arm64-v8a
```
