# TermVR v0.21.10012026111600

`TermVR` `v0.21.10012026111600` (`versionCode` `302100010`) bundles `gvx` `v0.21.10012026111600` (`3178313725b5`). It resolves a container startup panic on 16 KB Android devices with sealed kernel mappings and preserves panic headers in failure diagnostics.

## What changed

This patch release updates the `gvx` runtime to handle kernel-sealed memory regions on 16 KB host pages. It also improves error capture in `SandboxSupervisor` when the runtime exits early.

### Sealed-page systrap fix and startup diagnostics

On Linux kernels that seal mappings such as `[vdso]` or `[vvar]`, `systrap` initialization previously split `EPERM`-rejected ranges at 4 KB boundaries and panicked on 16 KB devices. `TermVR` also dropped early panic headers when `stderr` exceeded 12 lines.

- Upgraded pinned `gvx` runtime to `v0.21.10012026111600` (`3178313725b5`), aligning `unmapSegment` recursive splits in `systrap` to `hostPageSize`.
- Ignored `EPERM` in `forkStub` upper-range `munmap` sweeps and optional `SYS_MSEAL`, guarded stub gap math in `stubInit`, and handled restricted `seccomp` notification probes safely.
- Updated `SandboxSupervisor` to retain 12 head lines and 12 tail lines of `librungv.so` stderr and unwrap `ExecutionException` causes in `Containers` failure banners.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.21.10012026111600-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.21.10012026111600`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.21.10012026111600-arm64-v8a.apk --abi arm64-v8a
```
