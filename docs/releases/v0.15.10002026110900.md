# TermVR v0.15.10002026110900

`TermVR` `v0.15.10002026110900` is the first public release of the unrooted Linux container terminal for Android 12 and newer devices. This release tracks upstream `gvx` `v0.15.10002026110900` (`versionCode` `261109000`) and delivers all core runtime, GPU terminal, storage, networking, and build verification features.

## Highlights

This release includes an isolated user-space Linux runtime, a GPU-accelerated terminal surface, and built-in container recipes. Users run standard Linux distributions, persistent volumes, and local developer services without root access.

- **Debian 13 Default Runtime**: Launches `docker.io/library/debian:trixie-slim` out of the box with uncapped host memory and CPU by default. Users can still set explicit memory or core limits per profile when needed.
- **Concurrent Multi-Container Sessions**: Runs multiple sandboxes side by side across foreground service tabs and split panes. Background sandboxes support one-tap `Freeze` and `Resume` through rotating checkpoint slots.
- **Persistent Volumes and Android Files Bridge**: Creates, inspects, and mounts named `ext4lite` volumes alongside sandbox workspaces. Exposes `/workspace` directories to external Android editors through `TermVrDocumentsProvider` and Storage Access Framework (`SAF`) grants.
- **120 Hz OpenGL ES 3.0 Terminal**: Integrates `libghostty-vt` with static FreeType and HarfBuzz shaping for low-latency rendering up to `120 Hz`. Bundles `TermVR Mono NF` `v1.0.1` for English, Korean Hangul, CJK characters, ligatures, and Nerd Font symbols. Includes touch modifier latches and a two-row auxiliary key bar.
- **Networking, Proxies, and WireGuard**: Forwards guest ports to loopback by default, gates LAN `0.0.0.0` exposure, and generates LAN connection QR codes. Supports live switching across `HTTP`, `HTTPS`, `SOCKS5`, and `SOCKS4` proxies, dynamic host DNS resolution, and imported WireGuard tunnels.
- **Prebuilt Docker and K3s Recipes**: Ships ready-to-launch recipes for rootless Docker Engine (`docker:dind`) and single-node `k3s` Kubernetes clusters on dedicated `ext4lite` volumes.
- **Offline Open-Source Licenses**: Bundles license texts for `gvx`, `libghostty-vt`, FreeType, HarfBuzz, Go, AndroidX, Kotlin, and `TermVR Mono NF` inside an offline viewer under `Settings`.

## Downloads

Each release ships architecture-specific APKs signed with Android APK Signature Scheme v2 and v3. One `arm64-v8a` package supports both 4 KB and 16 KB page-size Android 12+ devices.

| Artifact | Target Devices | Notes |
| :--- | :--- | :--- |
| `TermVR-v0.15.10002026110900-arm64-v8a.apk` | Android 12+ (`arm64-v8a`) phones and tablets | Unified binary for 4 KB and 16 KB page sizes. |
| `TermVR-v0.15.10002026110900-x86_64.apk` | Android 12+ (`x86_64`) emulators and devices | Matches `x86_64` host kernels and 16 KB emulator images. |
| `SHA256SUMS` | Checksum manifest | Lists SHA-256 digests for both release APKs. |

## Reproducible Build and Verification

GitHub Actions builds every release APK offline from pinned commits in `scripts/source-lock.json` and verifies bit-for-bit clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`). GitHub attaches `SLSA` v1.0 Build Level 2 provenance to all release assets.

Verify downloaded APKs and their v2/v3 signatures with these commands.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.15.10002026110900-arm64-v8a.apk
```

Verify bit-for-bit F-Droid build reproducibility from tag `v0.15.10002026110900`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.15.10002026110900-arm64-v8a.apk --abi arm64-v8a
```
