# TermVR v0.24.10012026112300

`TermVR` `v0.24.10012026112300` (`versionCode` `302400010`) bundles `gvx` `v0.24.10012026112300` (`95918a156297`). It keeps all existing container profiles, workspaces, and persistent `ext4lite` volumes compatible.

## What changed

This release advances the embedded `librungvx.so` runtime to upstream `gvx` `v0.24.10012026112300` while retaining `gVisor` `release-20261123.0` (`83df8eae069e`).

### Runtime upgrade to `gvx` `v0.24.10012026112300`

Upstream `gvx` `v0.24.10012026112300` (`95918a156297`) adds deterministic `pgalloc` releaser status helpers and isolates Linux `systrap` idle-stub leak tests from external host scanners.

- Upgraded pinned `gvx` runtime to `v0.24.10012026112300` (`95918a156297`), adding `MemoryFile.AllocationStats` and `MemoryFile.WaitReleaserIdle` in `pgalloc` (`gvx#263`, `gvx#264`).
- Included `SEEK_DATA` and `SEEK_HOLE` leak verification for Linux `systrap` idle stubs across 4 KB and 16 KB host pages.
- Updated `CheckpointController.DEFAULT_GVX_VERSION`, `scripts/source-lock.json`, `gradle/libs.versions.toml`, `fdroid/dev.gfire.termvr.yml`, and bundled license notices.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.24.10012026112300-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.24.10012026112300`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.24.10012026112300-arm64-v8a.apk --abi arm64-v8a
```
