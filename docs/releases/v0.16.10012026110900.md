# TermVR v0.16.10012026110900

`TermVR` `v0.16.10012026110900` (`versionCode` `301600010`) upgrades the bundled `gvx` runtime to `v0.16.10012026110900` (`fd2571c34f87`). It updates terminal input handling, guest shell defaults, compact tab controls, checkpoint lifecycles, and nested container execution on 16 KB `arm64` kernels.

## What changed

This release pairs `gvx` kernel fixes (`#198`, `#201`, and `#202`) with terminal UI, multiplexer, and runtime supervisor improvements. Every section below summarizes the user-visible changes across terminal input, shell environments, lifecycle controls, and container recipes.

### Special keys, IME chords, and ordered PTY writes

Touch modifier keys and soft keyboards now dispatch control chords consistently across native and fallback VT backends. A single-thread FIFO writer preserves input byte order and ignores closed or exited panes.

- Fixed `AuxiliaryKeyBar` modifier latch rendering so one-shot `CTRL` and `ALT` highlights clear immediately after a chord.
- Flushed active IME composition buffers cleanly and encoded `CTRL` and `ALT` chords typed through soft keyboards.
- Extended `libghostty-vt` and fallback key encoders to emit C0 control bytes for punctuation and shifted letters.
- Serialized PTY writes on `termvr-pty-writer` so fast soft-keyboard input preserves character order without racing closed streams.

### UTF-8 locale, bash shells, btop exit, and naming

Guest containers now open interactive `bash` shells with a UTF-8 locale when `bash` exists in the image. `gvx` `v0.16.10012026110900` also fixes non-canonical pseudo-terminal reads so full-screen tools exit without hanging.

- Set `LANG=C.UTF-8` across guest sessions and selected `/bin/bash` before `/bin/sh` when images include `bash`.
- Fixed `devpts` POSIX `VMIN` and `VTIME` replica reads in `gvx` (`#198`), allowing `btop` to exit cleanly on `q`.
- Updated default container and tab labels from `Dev Shell` and `#1` to `Debian` and `Shell 1`.
- Bypassed outbound proxy environment variables for loopback (`127.0.0.0/8`, `::1`) and sandbox subnet (`10.0.2.0/24`) destinations inside `termvr-agent`.

### Compact smartphone tab close confirmation

Narrow phone screens now prevent accidental tab closure next to the new-tab button. Exited tabs still close in one tap without extra confirmation prompts.

- Enlarged the tab close touch target and hid inline `×` icons on unselected tabs on compact widths.
- Added a `Close tab?` confirmation dialog when closing a live tab or split pane on compact screens.
- Closed tabs whose shell already exited immediately without opening the confirmation dialog.

### Pause, resume, and checkpoint lifecycle hardening

Activity transitions, background restores, and snapshot cleanup now keep GL surfaces, mux streams, and `ext4lite` volumes synchronized. `gvx` `v0.16.10012026110900` (`#202`) also retains guest memory mappings until platform teardown finishes and validates task state before saving snapshots.

- Synchronized OpenGL ES 3.0 render thread teardown, `NativeVtSession` locks, per-tab surface controllers, and foreground service resume flows.
- Marked consumed `active-slot.json` checkpoints superseded after restore or explicit container stop so subsequent cold starts boot cleanly.
- Updated `CheckpointController.DEFAULT_GVX_VERSION` and `scripts/sync-gvx-version.sh` so runtime upgrades supersede snapshots written by older `gvx` builds.

### Nested Docker and Kubernetes on 16 KB arm64 hosts

`gvx` `v0.16.10012026110900` (`#201`) repairs 16 KB `arm64` sub-block page unmapping when ELF `.relr.dyn` relocations span 4 KB sub-pages. Both `Docker Engine (DinD)` on `overlay2` and `Kubernetes Single-Node (k3s)` now run unmodified `nginx:alpine` workloads on 16 KB `arm64` kernels.

- Fixed `systrap` `subBlockLayer.unmap` generation tracking in `gvx` (`#201`) to eliminate zero-read `SIGILL` crashes in Alpine musl binaries.
- Verified `docker:dind` (`overlay2` on `ext4lite`) and single-node `k3s` pod and `ClusterIP` service traffic on Android 16 16 KB `arm64`.

## Reproducible build and verification

GitHub Actions builds every release APK offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.16.10012026110900-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.16.10012026110900`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.16.10012026110900-arm64-v8a.apk --abi arm64-v8a
```
