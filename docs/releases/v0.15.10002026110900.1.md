# TermVR v0.15.10002026110900.1

`TermVR` `v0.15.10002026110900.1` (`versionCode` `261109001`) adds persistent `ext4lite` root filesystems, repairs terminal query and `clear` handling, and fixes container `Freeze` and `Resume`. This release continues to track upstream `gvx` `v0.15.10002026110900` (`098291e096a9`) and ships with `TermVR Mono NF` `v1.1.0` and updated GitHub Actions workflows.

## What changed

This update fixes package persistence across container stops, TUI rendering on standard terminfo profiles, checkpoint stability, and `docker:dind` or `k3s` startup on `arm64`. All changes work on Android 12 and newer devices without root access.

### Persistent root mode with ext4lite

Container creation and launch dialogs now include an optional persistent root checkbox backed by `ext4lite` storage. Turning on this option keeps installed packages and configuration files across full container stops and restarts.

- Backs `/` with a dedicated `rootfs-<id>.ext4` volume via `pivot_root` instead of keeping root changes in ephemeral memory.
- Preserves packages from `apt`, `apk`, and `dnf`, along with files in `/etc` and `/root`, when you stop and restart a container.
- Shows the root volume under `Files > Volumes` for inspection and removes it automatically when you delete the container.

### Terminal emulation and TERM compatibility

Guest shells now boot with standard `xterm-256color` metadata and full writeback for terminal capability queries. Screen clears, cursor blink redraws, and window resizes behave consistently across `fastfetch`, `clear`, `tput`, and full-screen TUIs.

- Switched the default guest `TERM` to `xterm-256color` alongside `COLORTERM=truecolor` and `TERM_PROGRAM=TermVR`.
- Wired `libghostty-vt` query replies (`CPR`, `DSR`, `DA1`, `DA2`, `XTWINOPS`, `DECRQM`, `XTVERSION`, `OSC 10/11`, and Kitty graphics) back to the PTY.
- Fixed OpenGL ES 3.0 viewport clearing, scrollback clearing, and cursor redraws when applications emit `ED 2` or `ED 3` (`clear`).
- Forwarded pre-launch cell and pixel dimensions on `openPty` so initial shells open at the exact screen size.
- Preserved `O_NONBLOCK` during `TIOCSWINSZ` via Go `SyscallConn()` so PTY reads never block during resizes.

### Snapshot Freeze and Resume

Checkpoint save and restore paths now handle socket setup and tab reconnection reliably under `hostlockdown`. Restored containers recover running shells and background jobs cleanly.

- Fixed `LocalSocket` listener accept ordering and JSON control request framing for `rungv` checkpoints.
- Pre-opened `-checkpoint-dir` before `hostlockdown` seals host filesystem access.
- Rebound `termvr-agent` mux tabs to restored pseudo-terminals after `Resume` finishes.

### Docker, k3s, and defaults

Built-in recipes and documentation now reflect uncapped host resource defaults and verified emulator behavior.

- Removed default CPU and memory caps across all catalog container recipes.
- Added `arm64` `/proc/cpuinfo` synthesis and legacy `iptables` selection for `docker:dind` and single-node `k3s` guests.
- Mounted `/var/lib/rancher` on writable `overlayfs` inside the `k3s` recipe so cluster state initializes properly.
- Replaced placeholder SVGs in `README.md` with real Android 16 emulator screenshots, alongside bundled `TermVR Mono NF` `v1.1.0` and updated GitHub Actions dependencies.

## Reproducible build and verification

GitHub Actions builds every release APK offline from pinned commits in `scripts/source-lock.json` and verifies bit-for-bit clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`). GitHub attaches `SLSA` v1.0 Build Level 2 provenance to all release assets.

Verify downloaded APKs and their v2/v3 signatures with these commands.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.15.10002026110900.1-arm64-v8a.apk
```

Verify bit-for-bit F-Droid build reproducibility from tag `v0.15.10002026110900.1`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.15.10002026110900.1-arm64-v8a.apk --abi arm64-v8a
```
