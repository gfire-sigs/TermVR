# TermVR v0.26.10002026112300

`TermVR` `v0.26.10002026112300` (`versionCode` `302600000`) bundles `gvx` `v0.26.10002026112300` (`4d5ff9e33b51`). It keeps all existing container profiles, workspaces, and persistent `ext4lite` volumes compatible.

## What changed

This release advances the embedded `librungvx.so` runtime to upstream `gvx` `v0.26.10002026112300` while retaining `gVisor` `release-20261123.0` (`83df8eae069e`).

### Runtime upgrade to `gvx` `v0.26.10002026112300`

Upstream `gvx` `v0.26.10002026112300` (`4d5ff9e33b51`) adds opt-in contained host symbolic links for `hostfs` bind mounts and enforces containment checks across directory and link mutations.

- Upgraded pinned `gvx` runtime to `v0.26.10002026112300` (`4d5ff9e33b51`), adding opt-in contained host symbolic links (`--mount ...,symlinks=contained`) for `hostfs` bind mounts (`gvx#267`, `gvx#278`).
- Included serialized containment checks across `rename`, `RENAME_EXCHANGE`, `RENAME_WHITEOUT`, and `link`, identity-keyed host symlink metadata, and virtual symlink inspection APIs (`gvx#278`).
- Updated `CheckpointController.DEFAULT_GVX_VERSION`, `scripts/source-lock.json`, `gradle/libs.versions.toml`, `fdroid/dev.gfire.termvr.yml`, and bundled license notices.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.26.10002026112300-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.26.10002026112300`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.26.10002026112300-arm64-v8a.apk --abi arm64-v8a
```
