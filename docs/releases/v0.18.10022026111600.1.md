# TermVR v0.18.10022026111600.1

`TermVR` `v0.18.10022026111600.1` (`versionCode` `301800021`) bundles `gvx` `v0.18.10022026111600` (`14ac125f1871`), ships signed Accrescent `.apks` split archives, and launches the self-hosted F-Droid repository on GitHub Pages.

> [!IMPORTANT]
> This release introduces the permanent backed-up release signing key (`SHA-256: 23FAEDB73343D4AE06DD849FCF803B39DA420A11B32AF8EF4EA1F63E1A5AC257`). Uninstall earlier sideloaded APKs before installing this release; all future releases keep this signing key.

## What changed

This release upgrades distribution pipelines and verification metadata on top of `TermVR` `v0.18.10022026111600` (`GHSA-424c-p5c6-jhhm` security fixes, indefinite wake lock default, and `arm64`/`amd64` runtime hardening).

### Multi-channel distribution and attestation

Every release now produces verified binaries for direct APK install, Obtainium, the self-hosted F-Droid repository, and Accrescent.

- Added `bundletool` `1.18.3` (`SHA-256` pinned in `scripts/source-lock.json`) to produce signed `TermVR-v0.18.10022026111600.1.apks` split APK sets for Accrescent.
- Extended `scripts/verify-16kb-alignment.sh` to verify 16 KB `PT_LOAD` alignment inside every nested split APK of `.apks` archives.
- Added `scripts/publish-fdroid-repo.sh` and automated `gh-pages` publishing for the self-hosted F-Droid repository (`https://gfire-sigs.github.io/TermVR/fdroid/repo?fingerprint=74B6DE16E15A0FA8330D6013902E5F87348E69EA49E19FEF39FF7B52CD9120D3`).
- Added direct SLSA build provenance attestation links to GitHub Release notes and Obtainium install links to `README.md`.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.18.10022026111600.1-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.18.10022026111600.1`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.18.10022026111600.1-arm64-v8a.apk --abi arm64-v8a
```
