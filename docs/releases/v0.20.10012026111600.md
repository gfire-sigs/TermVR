# TermVR v0.20.10012026111600

`TermVR` `v0.20.10012026111600` (`versionCode` `302000010`) bundles `gvx` `v0.20.10012026111600` (`cc04f5ba8790`) and integrates the `gvx-ctrl/2` control surface for running containers.

## What changed

This release integrates live lifecycle, resource, port, mount, process, and kernel-log controls over `gvx-ctrl/2`. It preserves host lockdown and LAN exposure protections.

### Live container control over `gvx-ctrl/2`

`TermVR` drives running and paused containers over owner-only Unix domain sockets. It uses binary-framed `gvx-ctrl/2` calls and Unix `SCM_RIGHTS` descriptor passing.

- Added `GvxControlClient` in `:core:runtime-gvx` for binary-framed `GVX2` calls, `SCM_RIGHTS` descriptor passing, and structured error decoding.
- Added instant in-memory `Pause` and `Resume` (`SandboxRunState.PAUSED`) alongside disk checkpoint `Freeze`. Stopping sends `lifecycle.stop`, and `RAW_PTY` containers read `sandbox.stats`.
- Added live RAM, CPU, and `PIDs` limit updates in `Edit Container`. Added live toggling of LAN egress isolation in `Network` without restarts.
- Enabled `--dynamic-ports` and opt-in `--auto-publish` for NAT sandboxes so loopback TCP and UDP rules apply live. LAN (`0.0.0.0` and `[::]`) binds keep Wi-Fi confirmation dialogs and staged restarts.
- Enabled `--allow-volume-attach` with Android `SCM_RIGHTS` support in `gvx` `v0.20.10012026111600` so named `ext4lite` volumes attach and detach live.
- Added the **Container Inspector** dialog on `HomeScreen` with four tabs: `Stats`, `Processes` (`TERM`/`KILL`), `Mounts` (live `RO`/`RW` remount and unmount), and `dmesg` (`Clear`).

### Release and workflow reliability

This release tag includes the PyPI `fdroidserver` fix for indexing of Android 16 (API 36) APKs on the self-hosted F-Droid repository. It also updates `.github/workflows/sync-gvx.yml` to warn cleanly when repository policy blocks automated pull requests.

## Reproducible build and verification

GitHub Actions builds every release artifact offline from pinned commits in `scripts/source-lock.json` and verifies clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`), and GitHub attaches `SLSA` v1.0 Build Level 2 provenance.

Run these commands to verify downloaded APKs and their v2 and v3 signatures.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.20.10012026111600-arm64-v8a.apk
```

Run `./scripts/verify-reproducible-apk.sh` to verify F-Droid build reproducibility from tag `v0.20.10012026111600`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.20.10012026111600-arm64-v8a.apk --abi arm64-v8a
```
