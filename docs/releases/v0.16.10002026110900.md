# TermVR v0.16.10002026110900

`TermVR` `v0.16.10002026110900` (`versionCode` `301600000`) upgrades the bundled `gvx` runtime to `v0.16.10002026110900` (`a9bfd06c2c07`) and moves **Persistent root (`ext4lite`)** mode onto `gvx`'s native `-rootfs-volume` overlay upper layer.

## What changed

This release removes the old guest `pivot_root` staging path and switches `TermVR` to a monotonic Android `versionCode` scheme so upgrades from `v0.15.10002026110900.1` install cleanly.

### Native persistent rootfs with gvx -rootfs-volume

When **Persistent root (`ext4lite`)** is enabled, `gvx` mounts the container's `rootfs-<id>.ext4` volume directly as the writable overlay upper layer before guest PID 1 starts.

- Removed first-boot rootfs copying, `/.termvr-rootfs` staging, and `pivot_root` logic from `termvr-agent`, making cold starts instant even on large Debian and Ubuntu images.
- Preserved installed `apt`, `apk`, and `dnf` packages, `/etc` edits, and overlay whiteouts across full container stops and restarts.
- Removed the `termvr-agent --exec` wrapper in `RAW_PTY` mode because `gvx` attaches `-rootfs-volume` natively before starting the guest shell.
- Kept full `Freeze` and `Resume` checkpoint compatibility by passing matching `-rootfs-volume` flags on both `rungv run` and `rungv restore`.
- Updated the `Files > Volumes` browser to attach stopped `rootfs-<id>` volumes with `-rootfs-volume` and inspect the merged `/` filesystem instead of raw `upper/` and `work/` directories.

### Monotonic Android versionCode

Previous `YYMMDDGGR` version codes ignored the `gvx` minor version and release counter when upstream published on the same gVisor date.

- Updated `scripts/sync-gvx-version.sh` to encode `major`, `minor`, the 3-digit `gvx` counter, and `app_revision` into a monotonic 9-digit integer (`301600000` for `v0.16.10002026110900`, above `261109001`).

## Downloads

Each release ships architecture-specific APKs signed with Android APK Signature Scheme v2 and v3. One `arm64-v8a` package supports both 4 KB and 16 KB page-size Android 12+ devices.

| Artifact | Target devices | Notes |
| :--- | :--- | :--- |
| `TermVR-v0.16.10002026110900-arm64-v8a.apk` | Android 12+ (`arm64-v8a`) phones and tablets | Unified binary for 4 KB and 16 KB page sizes. |
| `TermVR-v0.16.10002026110900-x86_64.apk` | Android 12+ (`x86_64`) emulators and devices | Matches `x86_64` host kernels and 16 KB emulator images. |
| `SHA256SUMS` | Checksum manifest | Lists SHA-256 digests for both release APKs. |

## Reproducible build and verification

GitHub Actions builds every release APK offline from pinned commits in `scripts/source-lock.json` and verifies bit-for-bit clean-room reproducibility before signing. All shared libraries align `PT_LOAD` segments to at least `16384` bytes (`16 KB`). GitHub attaches `SLSA` v1.0 Build Level 2 provenance to all release assets.

Verify downloaded APKs and their v2/v3 signatures with these commands.

```bash
sha256sum -c SHA256SUMS
apksigner verify --verbose --print-certs TermVR-v0.16.10002026110900-arm64-v8a.apk
```

Verify bit-for-bit F-Droid build reproducibility from tag `v0.16.10002026110900`.

```bash
./scripts/verify-reproducible-apk.sh --signed-apk TermVR-v0.16.10002026110900-arm64-v8a.apk --abi arm64-v8a
```
